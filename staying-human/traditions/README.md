# Traditions — the living archive

One directory per pillar. Each holds contributed traditions as markdown
files: what it is, where it comes from, and how to do it yourself.

A tradition entry should answer three questions:

1. **What is it?** — the practice itself
2. **Whose is it?** — its lineage: family, region, culture, era
3. **How do I keep it?** — enough detail that a stranger could practice it

See [`community/`](../community/) for the contribution template.
