Rate table — cost & price to owner per employee

Derived cost rate = Salaries ÷ Hours × overhead multiplier from this project's actuals (type in the Cost rate column to override a person). Enter each person's bill rate (price to owner) to get revenue and margin. Names must match the Employee/Vendor column exactly. Rates are saved per project and drive the cost, revenue and margin numbers on the Project Forecast and Actuals vs Forecast tabs. Rates can also be filled in Excel via the template on the Project Forecast tab (Rates sheet) and imported back.

Earned value — PV / EV / AC against the original baseline; cost basis = hours × cost rate

PV = baseline cost planned through the status date · AC = actual cost charged through it · EV = % complete × BAC per task. % complete defaults to an automatic measure (actual hours ÷ EAC hours from the updated forecast, capped at 100%) — type a physical % complete to override it; blank returns to auto. Overrides are saved per project.

Change order log — only Executed change orders flow into the forecast

Set each change order's status. Pending and Approved are tracked but change no numbers. Executed adds its deltas to the contract value (NTE cap), cost budget and contingency used across the Project Forecast and Actuals vs Forecast tabs. Rejected is archived. Δ values are positive to add scope/fee. Saved per project.

General settings

Saved data

Everything you type — forecasts, rates, budgets, mapping — is auto-saved in this browser as you work, and is restored when you reopen the file on this machine. For a durable copy, use Save in the header: in Edge/Chrome it asks where to put the workbook once, then writes back to that same file every time — just like Excel — and auto-saves to it every 2 minutes while you work. Save As… picks a new location or format. The default format is a real Excel workbook (.xlsx) with readable sheets (Data, Baseline Plan, Updated Forecast, Rate Table, Projects, Budgets) that anyone can open in Excel, plus a hidden state sheet so the tool reopens it exactly; JSON is available for a compact copy. Open restores either format — and keeps writing to that file when you Save. Keep workbooks on your desktop, OneDrive or SharePoint (synced SharePoint folders give you version history for free). Export/Import settings moves just the configuration, without data.

About

Single-file tool, runs entirely in your browser. Expected columns: Business Unit, Division, Sub Division, Cost Center, Project Manager, Project Number/Name, Employee/Vendor, Task hierarchy, Transaction Type, Expenditure Org/Type, Period Name, GL/Transaction Date, Hours, Salaries, Fringe, Subs Cost, Expenses Cost, Oncost, Total Cost, Bill Flag, Billed Status, Invoice Number, Comments. Any missing column simply disables the related feature — only a period source and at least one cost column are required.
