# Programs

How Staying Human takes traditions off the page and into rooms.

## Workshops
Hands-on sessions where a tradition keeper teaches a practice — bread,
letterpress, harmony singing, whittling. Small groups, no screens, real
materials.

## Seasonal Gatherings
Quarterly events tied to the calendar — harvest tables, solstice fires,
new-year letter-writing nights. Open to all, designed around the pillars.

## Tradition Keepers
A matching program pairing elders and practitioners with learners for
sustained, person-to-person transmission — apprenticeship for the ordinary
sacred things.

## Planned structure

```
programs/
├── workshops/      # one file per workshop format
├── gatherings/     # seasonal event playbooks
└── keepers/        # matching program docs
```
